# 個人の日常Git操作

## 作業範囲

- ユーザーが明示した操作と対象だけを扱う。
- 関連しそうな設定、ファイル、ignoreパターン、ブランチ、コミット、push、整理作業を親切で追加しない。
- スキルへ新しい規則や操作を追加するのは、ユーザーが追加を依頼したときだけとする。

## 個人ルール

- リポジトリ直下の`_`で始まるフォルダは、明示された例外を除き、その中身を含めてGit管理外とする。
- Git管理設定を扱う依頼では、`.gitignore`へ`/_*/`を記載する。例外はユーザーが指定した場合だけ追加する。
- 対象がすでに追跡されている場合は追跡状態を示し、インデックスから外す操作はユーザーの依頼範囲に含まれる場合だけ実行する。
